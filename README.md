# HH Auto Apply

Локальное приложение для macOS: ищет вакансии на hh.ru, сравнивает их с выбранным
резюме через внешний LLM и помогает готовить или отправлять отклики. Dashboard работает
на вашем Mac, а HH открывается в Chromium через Playwright. Для LLM и необязательной
Anti-Captcha нужны отдельные внешние сервисы и их ключи.

## SAFE и LIVE

- **SAFE** анализирует вакансии и готовит письма без отправки откликов.
- **LIVE** разрешает реальные отклики, но каждый новый run требует отдельного явного
  подтверждения. Сохранённый LIVE сам ничего не запускает.

## Быстрый старт

Установите нативный Python 3.11 и проверьте, что команда `python3 --version`
показывает именно его. Нужны macOS и доступ в интернет. После публикации скачайте
исходники, откройте Terminal в папке проекта и выполните:

```bash
bash setup.sh
bash start.sh
```

Откройте `http://127.0.0.1:8000`, войдите в HH вручную через dashboard, обновите список
резюме и выберите своё. Настройте хотя бы одно LLM-подключение со своим ключом и сначала
выполните SAFE-прогон. Проверка подключения не гарантирует успех реального запроса.
Для LIVE сохраните соответствующий режим и отдельно подтвердите каждый запуск.

Настройки хранятся локально в `.env`; безопасный шаблон — `.env.example`.

## Безопасность

LIVE взаимодействует с реальным аккаунтом HH. Не используйте реальные отклики как тест.
`applied_confirmed` допустим только после явного подтверждения HH; `submission_unknown`
требует ручной проверки и блокирует слепой повтор.

LLM получает sanitized профессиональный контекст и текст вакансии. Не публикуйте `.env`,
`state/`, `private/`, HH session/cookies, API keys, contacts, resume cache и runtime logs.
Dashboard слушает только localhost.

При включённой интеграции Anti-Captcha однозначная графическая CAPTCHA может
обрабатываться автоматически (до трёх платных задач на последовательность). Это
подтверждено отдельными LIVE-прогонами, но не гарантирует прохождение каждой проверки.
При неизвестном результате программа удерживает текущую вакансию для ручного решения.
Автоматизация UI может противоречить правилам hh.ru и несёт риск для аккаунта.
Версия для Windows не проверена и не поддерживается инструкцией установки.
