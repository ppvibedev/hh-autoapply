# Из чего состоит приложение и какие инструменты задействует

Инструмент работает **полностью локально** на Mac, слушает только `127.0.0.1:8000` — наружу ничего не публикует.

## 1. Языки и среда
- **Python 3.9+** — весь бэкенд (движок прогона, сервер, логика).
- **HTML + CSS + JavaScript** — дашборд (`web/index.html`), без фреймворков, чистый JS.

## 2. Python-библиотеки (ставятся `setup.sh`)
| Библиотека | Зачем |
|---|---|
| **Flask** | локальный веб-сервер дашборда (кнопки, API, страница) |
| **Playwright** | управление браузером — поиск, чтение вакансий, клики отклика |
| **requests** | HTTP-запросы: ИИ-провайдеры, справочник регионов hh |
| **python-dotenv** | чтение настроек из `.env` |

## 3. Внешняя программа
- **Chromium** — браузер, который ставит Playwright (`playwright install chromium`). Через него бот ходит по hh.ru под твоей сессией. Отдельный от твоего Chrome/Safari.

## 4. Внешние сервисы и API
| Сервис | Как используется |
|---|---|
| **hh.ru (сайт)** | поиск и отклик — через Chromium под твоим логином |
| **hh.ru API `/areas`** | справочник регионов/городов для выпадающего списка (открытый, без ключа) |
| **ИИ-провайдер** | генерация писем. Один из: **YandexGPT** (РФ, без VPN), **Claude (Anthropic)** или **OpenAI** — по твоему API-ключу |

Больше внешних сервисов нет: ни своего сервера в облаке, ни базы данных, ни аналитики.

## 5. Внутренние модули (из чего собран код)
| Файл | Роль |
|---|---|
| `webapp.py` | веб-сервер дашборда (Flask): страница + API кнопок |
| `web/index.html` | сам интерфейс |
| `run_web.py` | движок прогона (поиск → фильтры → скоринг → письмо → отклик) |
| `hh_web.py` | работа с сайтом hh.ru; все селекторы страниц собраны здесь |
| `decide.py` | принятие решения: HARD-фильтры + скоринг + текст письма |
| `llm.py` | обращение к ИИ (Claude/OpenAI/YandexGPT) |
| `browser.py` | запуск Chromium + загрузка сессии |
| `login.py`, `login_web.py` | вход в hh.ru (пароль вводишь сам) |
| `list_resumes.py` | сбор списка твоих резюме |
| `config.py`, `envfile.py` | настройки, чтение/запись `.env` |
| `hh_client.py`, `run.py` | запасной путь через официальное API (только поиск) |
| `setup.sh`, `start.sh`, `cleanup.sh`, `hh-autoapply.command` | установка / запуск / очистка / ярлык |

## 6. Локальные файлы данных (папка `state/`)
- `session.json` — сохранённая сессия hh.ru (куки входа);
- `resumes.json`, `resume.txt` — список и текст резюме;
- `seen.json` — уже просмотренные вакансии (дедуп);
- `decisions.jsonl` — лог всех решений;
- `run.pid` — метка активного прогона;
- `.env` — настройки и API-ключ.

## 7. Чего НЕ использует
- Нет облачного сервера, нет БД, нет сторонней аналитики/телеметрии.
- Пароль hh.ru нигде не хранится — только сессия (куки).
- Не связано с рабочими проектами — отдельный личный инструмент.

## Итог
**Python + Flask (сервер) + Playwright/Chromium (браузер) + ИИ по ключу (письма) + сайт hh.ru (данные).** Всё крутится локально на твоей машине.
