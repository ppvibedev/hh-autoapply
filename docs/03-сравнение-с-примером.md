# Отличие от GitHub-примера (jointime1/n8n-hh.ru)

Репозиторий [jointime1/n8n-hh.ru](https://github.com/jointime1/n8n-hh.ru) взят за образец
**только в идее**: раз API hh не даёт сторонним приложениям отправлять отклики, надо
ходить **через сайт под залогиненной сессией** (Playwright). Остальное построено иначе и проще.

## Что общего (взято оттуда)
- **Подход:** автоматизация браузера (Playwright), а не официальное API.
- **Вход:** один раз логинишься руками, сессия сохраняется в файл.
- **Паузы** между действиями против антибота; капчу не обходим.

## Чем наш проект отличается

| Аспект | Тот репозиторий | Наш проект |
|---|---|---|
| **Оркестрация** | Нужен **n8n** (отдельная low-code платформа) | Self-contained: один Python-скрипт + движок, **n8n не нужен** |
| **Запуск/деплой** | **Docker Compose**, 2 контейнера (API + n8n) | `setup.sh` + **двойной клик по ярлыку**, без Docker |
| **Интерфейс** | Swagger `/docs` — API для разработчика (`/search`, `/apply`, `/health`) | Полноценный **веб-дашборд для человека**: вход, фильтры, выбор резюме, запуск/стоп, живая лента, письма |
| **Вход** | Через CLI-команду в терминале | Кнопкой **в дашборде** (окно входа открывается само) |
| **ИИ** | Google **Gemini** | **YandexGPT / Claude / OpenAI** по выбору (YandexGPT работает в РФ без VPN) |
| **Письма** | Передаётся готовый текст, «обогащение» через n8n | ИИ пишет письмо **под требования вакансии из твоего резюме** и прикрепляет через реальный «Добавить сопроводительное» |
| **Фильтры** | Базовые (текст + страница) | Все родные фильтры hh (опыт, занятость, график, формат, период, сортировка) **+ свои** (стоп-слова, чёрный список, порог) |
| **Отбор/скоринг** | Не выражен явно | HARD-фильтры + скоринг по названию + порог |
| **Безопасность** | Минимум (только задержки) | Дневной лимит, **один прогон одновременно**, kill-all «Стоп», баннер «идёт прогон», дедуп, ранее — shadow-режим |

## Суть отличия одной фразой

Тот проект — **набор API-эндпоинтов, которым дирижирует внешний n8n в Docker** (для
разработчика). Наш — **готовое локальное приложение с человеческим интерфейсом**: поставил,
двойной клик, вошёл, выставил фильтры, нажал «Запустить» — без n8n, без Docker, с ИИ,
который пишет письма под твоё резюме, и с защитами от рассылки мимо/дублей.

От образца взята только базовая механика (браузер + сессия), а архитектура, интерфейс,
ИИ и логика отбора/писем — свои и заметно проще в использовании.
