# Как происходит установка программы

Разбор: что реально происходит, поднимается ли сервер, и что доустанавливается.

## Что делает установка (`setup.sh`)

1. **Создаёт изолированное окружение Python** (`.venv`) — папку **внутри проекта**. Все библиотеки ставятся только туда, **системный Python не трогается**.
2. **Ставит 4 Python-библиотеки** в это окружение: Flask, Playwright, requests, python-dotenv.
3. **Скачивает браузер Chromium** (~150 МБ) в пользовательский кэш Playwright (`~/Library/Caches/ms-playwright`). Это отдельный браузер для автоматизации, твой Chrome/Safari не затрагивает.

Всё. **Без прав администратора (sudo не нужен)**, ничего системного не меняется.

## Про сервер — да, но локальный и временный

- При запуске приложения (двойной клик по ярлыку) поднимается **локальный веб-сервер** (Flask) на `127.0.0.1:8000`.
- Доступен **только на твоём компе** — не из интернета, не из локальной сети.
- Работает, **только пока открыто окно** запуска. Закрыл окно — сервер остановился. Это **не служба**, которая висит постоянно и стартует с системой.

## Node.js и прочее — НЕ нужны

- **Node.js не устанавливается и не нужен.** Интерфейс — обычный HTML-файл, который отдаёт Flask; никакой сборки, npm, node_modules.
- Никакие другие среды (Docker, БД, серверы) не ставятся.

## Что должно быть заранее

Только **Python 3.9+**. На Mac обычно уже есть (проверка: `python3 --version`). Если нет — ставится отдельно (python.org или Homebrew). `setup.sh` Python сам не ставит — он его использует.

## Что окажется на диске

| Что | Где | Размер |
|---|---|---|
| Код программы | папка `hh-autoapply` | ~100 КБ |
| Python-библиотеки | `hh-autoapply/.venv` | ~50–80 МБ |
| Браузер Chromium | `~/Library/Caches/ms-playwright` | ~150 МБ |

Итого ~200–250 МБ, в основном Chromium.

## Как удалить полностью

- Удалить папку `hh-autoapply` (заберёт код + `.venv`).
- По желанию — папку `~/Library/Caches/ms-playwright` (Chromium).
- Системе ничего не остаётся: реестров/служб нет.

## Итог
Ставится **изолированно в свою папку, без прав админа, без Node**; поднимается **локальный сервер только на время работы**; единственное требование заранее — **Python 3.9+**.
